# Solver feasibility

All counts from 3 to 21 have been generated in PureBasic and passed an independent Python verifier. The largest output contains 190 sittings and covers all 3990 person-and-neighbour-pair requirements.

## Selected methods

For 3, 4, 5, 6, 8, 9, 10, 12, 14, 17, 18, and 20 people, use the projective finite-field construction in Nakamura, Kiyasu-Zen'iti and Ikeno (1980), pp. 7-10. Set q = n - 1. Find a fractional linear transformation forming one cycle on the q field elements plus infinity. Apply all affine transformations to this cycle, retaining one seating from each reversal pair. The experimental implementation verifies the resulting rows rather than relying on transcription of a formula.

For 7, 11, 13, 15, 16, 19, and 21 people, expand compact published starting rows under their stated label cycles. Keep the fixed labels unchanged. Each group is generated by repeatedly applying the same label permutation. There are 49 stored starting rows across these seven cases; complete schedules are generated at runtime. These construction seeds are explicit data dependencies, and must ship with attribution.

The seeds for 7 and 11 are from Dudeney's solution 273. The others are numerical data from the 1980 paper's appendix, pp. 17-19. These pages were rendered and visually checked; OCR alone was not trusted. Source labels beginning at 0 are converted to labels beginning at 1.

Sources: [1980 paper](https://rikkyo.repo.nii.ac.jp/record/10276/files/AA00610867_29-01_02.pdf), [Dudeney's book](https://www.gutenberg.org/ebooks/16713). The associated Python data file is [starters.py](../../experiments/round-table/starters.py).

## Reproduce

From the project root:

```sh
python3 experiments/round-table/build_probe.py
python3 -m unittest discover -s experiments/round-table -p 'test_*.py'
python3 experiments/round-table/benchmark.py
```

Python uses only its standard library. The final application will run in PureBasic without Python. The probe's build helper generates a PureBasic include from the attributed starter data; the delivered application's build must not require that helper.

## Decision and limits

Use these verified constructions for the initial range. A generic cyclic search did not find complete schedules within the exploratory limits (30 seconds for 13; 60 seconds for 21); timeout establishes no impossibility. That experiment is retained for research only and is not part of the selected runtime design.

The supported range is bounded by validated constructions, rather than integer size. Extending it requires another verified construction or new starting rows. Generating independently discovered seeds from scratch is separate work.

No GUI or production verifier has been implemented in this milestone. Their acceptance checks remain in the production plan.
